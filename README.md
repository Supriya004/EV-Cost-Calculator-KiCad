EV Cost Calculator — KiCad PCB Design

About the Project
This is a learning project created using KiCad 9 to practice electronic circuit design, PCB layout, component placement, and track routing for an EV Cost Calculator system.

Project Preview

![EV Cost Calculator PCB 3D View](pcb-3d-view.png)

Components Used
- Arduino UNO R3
- ACS712 current sensor
- Voltage sensor connector
- Temperature sensor connector
- 16x2 I²C LCD connector
- Relay
- LEDs and resistors
- Buzzer
- Push buttons

Tools Used
- KiCad 9 — schematic design and PCB layout

Project Status
The schematic and PCB layout were created for learning and practice. Some connections remain unrouted, so this design is **not a manufacturing-ready PCB**.

Files
-`cost_calculator.kicad_sch` — circuit schematic
- `cost_calculator.kicad_pcb` — PCB layout
- `cost_calculator.kicad_pro` — KiCad project settings

Created as a hands-on electronics design learning project.
